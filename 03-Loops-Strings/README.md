# Chapter 3: Loops & Strings

This section covers repetitive logic and text manipulation, two essential pillars of handling data in JavaScript.

## 🔑 Key Concepts

### 1. Loops
* **For Loop:** Best when the number of iterations is known.
* **While Loop:** Runs as long as a condition remains true.
* **Do-While:** Guarantees at least one execution.

### 2. Loop Control
* `break`: Exits the loop immediately.
* `continue`: Skips the current iteration and moves to the next.

### 3. String Methods
Strings are immutable in JS, meaning methods return a *new* string rather than changing the original.
* `.length`: Property to get text length.
* `.trim()`: Removes whitespace from both ends.
* `.slice(start, end)`: Extracts a section (excludes the 'end' index).
* `.toUpperCase() / .toLowerCase()`: Changes case.
* `include(char)`: Checks if a letter exists in the string
* `split(separator)`: Turns a string into an Array
