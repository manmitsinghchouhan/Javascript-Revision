# Chapter 4: Arrays

Arrays are ordered collections of data. In JavaScript, arrays can hold multiple data types and are dynamically resized.

## 🔑 Key Concepts

### 1. Indexing
* Arrays start at index `0`.
* Accessing an index that doesn't exist returns `undefined`.

### 2. Core Methods
* `push() / pop()`: Handle the end of the array.
* `unshift() / shift()`: Handle the start of the array.
* `.indexOf(value)`: Returns the index of a specific element.

### 3. Iteration
The most common way to process arrays is using a `for` loop combined with the `.length` property.
