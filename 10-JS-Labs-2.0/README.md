# 🧪 Logic Lab 2.0: Advanced Application Logic

This lab marks my transition from basic JavaScript syntax to building real-world, interactive features. It combines DOM Manipulation, Asynchronous Programming, and Advanced Array Methods.

## 🚀 Challenges Overcome

### 1. The Dynamic Task Manager
* **Concepts:** DOM Events, Objects, `classList`, and State Syncing.
* **The Win:** Learned how to link a JavaScript Object to a physical HTML element using closures and data-attributes.

### 2. Ghost User Profile Card
* **Concepts:** Fetch API, `async/await`, `try...catch...finally`, and Loading States.
* **The Win:** Implemented a defensive coding strategy where the UI remains stable even if the API returns a 404 or a network error.

### 3. Smart Student Directory
* **Concepts:** `.filter()`, `.sort()`, `input` events, and real-time rendering.
* **The Win:** Built a functional search engine that processes a data stream, organizes it alphabetically, and updates the DOM instantly as the user types.
